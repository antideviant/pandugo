# PanduGo

A vehicle management platform being developed as a **Minimum Viable Product (MVP)** to help users manage and track vehicle details, maintenance records, expenses, documents, and reminders.

## Status

🚧 Work In Progress — MVP Development

## Tech Stack

### Web & Backend

- PHP
- Laravel
- Livewire
- Alpine.js
- Tailwind CSS
- REST API
- Laravel Sanctum

### Mobile

- Flutter
- Dart
